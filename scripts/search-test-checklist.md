# Чеклист проверки поиска: локально vs Amvera

Цель: убедиться, что один и тот же запрос ведёт себя похоже на двух стендах.

## Стенды

| Стенд | Витрина | Backend |
|-------|---------|---------|
| Локально | http://localhost:3000 | http://localhost:9000 |
| Amvera | https://amper1.ru | https://amper-backen-dmitrykodbuster.msk1.amvera.tech |

Автосравнение API (нужен запущенный локальный backend):

```bash
node scripts/compare-search-local-prod.mjs
```

---

## Как тестировать руками (по каждому пункту)

1. Открой **локально** и **amper1.ru** в двух вкладках.
2. Вставь запрос в поиск → **Найти**.
3. Запиши: число «Показано», первые 3 названия, есть ли «Ничего не найдено».
4. Отметь результат: ок / расхождение / пусто на Amvera.

## Что считать нормой после починки индекса

- Для частых слов (лампа, розетка, кабель) числа **одного порядка** (не 10× разница).
- `ввг` / `ВВГ` / `VVG` все находят товары.
- Разделы вне электрики (топор, сверло, саморез) не «проваливаются» относительно локали сильнее, чем электрика.
